01 — Supervised Learning
Learns from Labeled Data
Algorithms trained on input–output pairs to predict outcomes on new data
01Linear RegressionSupervised

Fits a straight line through data to predict continuous numeric output by minimizing squared differences between predicted and actual values (OLS). Extends to multiple features via multiple linear regression.

Tabular
Use CasesHouse price prediction, sales forecasting, risk scoring
02Logistic RegressionSupervised

Despite the name, a classification algorithm. Applies a sigmoid function to a linear combination of features to output class probabilities. Fast, interpretable, strong baseline for binary and multi-class problems.

TabularNLP
Use CasesEmail spam, medical diagnosis, credit default
03Decision TreeSupervised

Recursively splits data by choosing the feature and threshold that best separates classes, maximizing information gain or reducing Gini impurity. Produces an interpretable, flowchart-like model.

Tabular
Use CasesLoan approval, customer churn, medical triage
04Random ForestSupervised

Trains hundreds of decision trees on random data and feature subsets (bagging), combining predictions by majority vote or averaging. Dramatically reduces overfitting and provides feature importance scores.

TabularCV
Use CasesFraud detection, feature ranking, clinical risk models
05Support Vector MachineSupervised

Finds the hyperplane maximizing the margin between classes. The kernel trick (RBF, polynomial) handles non-linear boundaries. Effective in high-dimensional spaces with limited training samples.

TabularCVNLP
Use CasesImage classification, text categorization, bioinformatics
06Convolutional Neural NetSupervised

Uses learned spatial filters sliding across images to detect a hierarchy of patterns — edges → textures → objects. Pooling layers add translation invariance. Dominant architecture for visual recognition.

CVNLP
Use CasesMedical imaging, autonomous driving, face recognition
07RNN / LSTMSupervised

Processes sequences step by step with a hidden state as memory. LSTM gates (input, forget, output) control information flow across time steps, solving the vanishing-gradient problem of vanilla RNNs.

NLPTabular
Use CasesTime-series forecasting, speech recognition, translation
02 — Unsupervised Learning
Finds Structure Without Labels
Discovers patterns and structure in unlabeled data
08K-Means ClusteringUnsupervised

Partitions data into k clusters by iteratively assigning each point to its nearest centroid, then recomputing centroids until convergence. k must be chosen in advance using the elbow method or silhouette score.

TabularCV
Use CasesCustomer segmentation, image quantization, anomaly detection
09Principal Component AnalysisUnsupervised

Finds orthogonal directions of maximum variance via eigendecomposition of the covariance matrix. Projecting onto top components reduces dimensionality while preserving the most information.

TabularCVNLP
Use CasesEDA, noise reduction, Eigenfaces (face recognition)
03 — Generative / Self-supervised
Learns to Generate at Scale
Pre-trained on massive data to model distributions and generate new content
10TransformerGenerative

Multi-head self-attention models relationships between all positions in a sequence simultaneously — no recurrence needed. Pre-trained via next-token prediction on massive corpora; fine-tuned for specific tasks. Foundation of all modern LLMs.

NLPCVGen AI
Use CasesChatGPT, Claude, BERT, ViT, DALL·E, code generation
