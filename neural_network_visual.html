02 — Components
Six Core Building Blocks
Every neural network is built from these fundamental elements
🧱Component 01
Layers

Organized groups of neurons processing information at each stage. The input layer receives raw data, hidden layers learn intermediate patterns, and the output layer produces the final prediction. Deeper networks learn more complex features.

ExampleA CNN for image recognition may have 50+ layers — early layers detect edges, later layers detect objects.
⚡Component 02
Neurons

The basic computing unit. Each neuron takes in inputs, multiplies them by weights, adds a bias term, and passes the result through an activation function. The output is sent to the next layer.

Formulaoutput = activation(w₁x₁ + w₂x₂ + ... + wₙxₙ + bias)
⚖️Component 03
Weights

Numerical parameters on each connection between neurons that determine how much influence one neuron has on the next. Initialized randomly, then updated during training via backpropagation to minimize loss.

AnalogyWeights are like volume knobs — controlling how loudly each input signal is heard by the next neuron.
📈Component 04
Activation Functions

Introduce non-linearity so the network can learn complex patterns. Without them, stacking layers is just matrix multiplication — still linear. ReLU is standard for hidden layers; Sigmoid and Softmax for outputs.

Common TypesReLU · Sigmoid · Tanh · Softmax · Leaky ReLU
🎯Component 05
Loss Functions

Measures how wrong the network's predictions are compared to true labels. Returns a single number — lower is better. The network's entire goal is to minimize this value. Choice depends on task type.

Common TypesMean Squared Error (regression) · Cross-Entropy Loss (classification)
🔧Component 06
Optimization Algorithms

Update the network's weights after each training step to reduce the loss. Gradient Descent moves weights in the direction that decreases loss. Adam and RMSprop adapt the learning rate per parameter for faster, more stable training.

Common TypesSGD · Adam · RMSprop · Adagrad · Momentum

Key Insights from TF Playground

Hands-on experimentation with the TensorFlow Playground made abstract concepts tangible — showing how each hyperparameter choice directly shapes model learning and performance.

🧩

Everything Is Connected

Poor weight initialization or a bad activation function cascades through the entire network.

🔁

Training Is Iterative

The network learns by repeatedly predicting, measuring error via loss, and adjusting weights through backpropagation.

⚙️

Hyperparameters Matter

Layers, neurons, learning rate, and activation functions all significantly impact how well and how fast a model learns.

📊

Noise Slows Learning

High noise requires more regularization. TF Playground clearly shows how noisy data slows convergence and lowers accuracy.

🎯

Non-linearity Is Essential

Without activation functions, no matter how many layers are added, the network can only learn linear boundaries.

🚀

Adam Beats SGD

Adam consistently outperforms basic SGD by adapting learning rates, making it the default for most deep learning tasks.
